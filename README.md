# Bus Management System

Desktop application for managing buses, drivers, and transport operations.  
This project demonstrates a simple management system built with **C#**, **.NET**, and **Windows Forms**.

The application allows administrators to manage buses, assign drivers, and update trip information through a graphical interface.

---

## Overview

This project demonstrates how a desktop application can be used to manage transportation data in a structured way.

The system includes a login interface and several management modules that allow the user to work with buses, drivers, and trip information.

Main focus of the project:

- desktop application development in C#
- Windows Forms user interface
- basic CRUD operations
- modular project structure

---

## Features

- User login system
- Bus management
- Driver management
- Trip management
- Update and edit records
- Desktop graphical user interface

---

## Application Modules

### Authentication

The application starts with a **login screen**, where the user must enter credentials to access the system.

### Bus Management

Allows administrators to:

- add buses
- edit bus information
- manage bus records

### Driver Management

Enables management of drivers including:

- adding drivers
- updating driver information
- maintaining driver records

### Trip Management

Provides functionality to update and manage transport trips.
